# Machine Translation and Speech Recognition Evaluation

**Course:** CIS 5300 / HW9  
**Artifact type:** Course project / coursework

## Overview

Implemented BLEU, chrF, and word error rate routines, compared zero-shot and few-shot translation, and evaluated Whisper transcription with added noise. Included gender-association and speaker-level error analyses.

## Guiding question

How do translation and speech metrics respond to lexical variation, noise, and subgroup differences?

## Methods and technical scope

Python; BLEU; chrF; WER; Whisper; LLM translation.

## Evaluation and analysis

Inspect metric disagreement and insertion, deletion, and substitution errors. Small course samples do not justify population-level fairness conclusions.
